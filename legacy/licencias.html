Licencias de Software y Recursos

Auditoría SBOM & Avisos a Terceros — Noviembre 2026

El ecosistema GymVIP está construido utilizando tecnologías de software libre y de código abierto de clase empresarial con licencias permisivas comerciales. Ninguna dependencia del stack productivo incorpora licencias restrictivas ("copyleft" viral agresivo que comprometa el código propietario) ni licencias de tipo "solo uso personal/no comercial" para la operación del gimnasio.

Se certifica mediante auditoría de dependencias (SBOM) que el proyecto no emplea activos marcados como "Creative Commons Non-Commercial (CC BY-NC)" ni licencias que impidan el uso productivo en el gimnasio.
